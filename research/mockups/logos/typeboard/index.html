userandproduct: type board

Six open-licence typefaces setting the one-word name. Every word on this page is a real font outline turned into an SVG path by tools/wordmark.py (shaped with HarfBuzz, so the font's own kerning applies). The big pair shows "and" in the lighter weight of the same family; the small row tries the red and blue accents. Look at the 16 px line first: a wordmark that falls apart there is out.

All six are under the SIL Open Font License 1.1, which allows logos made from the outlines. An outlined font is not exclusive, so the chosen face still needs a few custom touches. Fonts and licence files are in research/mockups/fonts/. Rebuild with python research/mockups/tools/build_typeboard.py. The dark-mode accents are lifted (#F0676C and #8EA2FF) because #B3141C and #1F3FBF are too dark to read on near-black.
