# Council 2 peer review, First Principles lens

**1. Strongest: D.** It is the only response that asks what is being sold before asking how to ship it. It strips the format away and finds the product: the owner's method (which questions, in what order, what quality bar). It names the real competitor, a blank ChatGPT box, rather than Notion. It also sees that judging a PRD is scarce while generating one is a commodity, which is where the reviewer-skill idea comes from. Its test is cheap and has a clear way to fail. B is the best build plan, but it accepts the premise without testing it.

**2. Biggest blind spot: A.** It treats the owner's method as already proven to be better than anything else. It also ignores capacity, even though one author is the stated binding constraint. "Chain the skills", a GitHub repo, a plugin listing, a paid team tier and three launch skills add up to a second product line before any article exists. Its GitHub backlink claim is a hope with no evidence behind it. It also says "prd template" is 2,900 searches, while B, D and E say 18,100.

**3. What all five missed.**
- **Nobody has shown the method beats a plain prompt.** Every response assumes it does, and none tests it. The first test should be a blind comparison: the owner's question set against "interview me and write a PRD", run on the same brief, with working PMs judging the two outputs. If the owner's set doesn't clearly win, the skill is worth nothing, whatever the format or launch plan.
- **The search figures conflict.** 2,900 against 18,100 for "prd template" was never reconciled. Settle it before anything is built on it.
- **The owner can use the skill first.** It can produce the worked examples that the template pages need anyway.
