To add an icon, fetch the same version: Pixelarticons from
`https://cdn.jsdelivr.net/npm/pixelarticons@2.4.1/svg/<name>.svg`, Phosphor from
`https://cdn.jsdelivr.net/npm/@phosphor-icons/core@2.1.1/assets/regular/<name>.svg` and
`.../assets/fill/<name>-fill.svg` (save the fill file without the suffix). Browse names at
pixelarticons.com and phosphoricons.com. One set per image; do not mix in Lucide, Tabler or others.

Second choices, only if a subject is missing from both: Lucide (ISC), Tabler (MIT), HackerNoon Pixel
Icon Library (CC BY 4.0: needs a credit line, so avoid unless paid).

## Photos for style 10

In order of preference:

| Source | Terms in short | Attribution |
|---|---|---|
| The owner's own photos | full rights; the strongest choice for authority | none |
| Unsplash (unsplash.com/license) | free commercial use and modification; no selling unaltered copies, no building a competing service; no rights to logos, trademarks or recognisable people beyond the photo | not required (appreciated) |
| Pexels (pexels.com/license) | free commercial use and modification; same resale and competing-service limits | not required |
| Library of Congress "Free to Use and Reuse" sets | public domain or no known restrictions; check each item's rights statement | credit is good practice |
| Openverse (search only) | finds CC and public-domain images but does not verify licences | per result; verify at the source |
| Wikimedia Commons | per file: public domain or CC BY are fine with credit; **avoid CC BY-SA** (share-alike would bind our image) | per file |

Rules:

- No recognisable faces without the person's consent; no brand logos or trademarks (a dot screen does
  not remove them).
- Our halftone or dither is a real modification, which keeps us clear of "unaltered copy" clauses.
- For any photo that is not the owner's, record the source URL, author and licence in the article's
  notes; the generator also stores the recipe (kind, style, background, scheme, slug, seed) in the PNG.
- Paid generation (only if the owner approves the spend): a single studio-style object photo from an
  image API as the source for the dot screen; the code still does the screen, palette and mark.
