# AI-generated content
More and more Shopping data is created using generative AI tools, and we now require some types of product data to be identified as being AI-generated. This article defines the product data that must be identified as being created using Generative AI.
#### In this article
- AI-generated images
- AI-generated product data
## AI-generated images
All images created using generative AI must contain meta data indicating that the image was AI-generated by using the IPTC DigitalSourceTypeTrainedAlgorithmicMedia metadata tag.
Important: Don't remove embedded metadata tags such as the IPTC DigitalSourceType property from images created using generative AI tools, for example Product Studio. The following IPTC NewsCodes specify the type of digital source that was used to create the image, and should be preserved:
- TrainedAlgorithmicMedia: The image was created using a model derived from sampled content.
- CompositeSynthetic: The image is a composite that includes synthetic elements.
- AlgorithmicMedia: The image was created purely by an algorithm not based on any sampled training data (for example, an image created by software using a mathematical formula).
AI-generated images can be used in the following attributes:
- Image link [image_link]
- Additional image link [additional_image_link]
- Lifestyle image link [lifestyle_image_link]
## AI-generated product data
When using AI-generated content for the title and description text attributes, an alternative attribute must be used instead of, or in addition to, the existing title [title] or description [description] attribute.
### Title
For titles created using generative AI, use the structured title [structured_title] attribute. The structured title [structured_title] attribute uses 2 sub-attributes:
- Digital source type [digital_source_type] (Required for content created using Generative AI): Provide the value “trained_algorithmic_media”, indicating that the title was created using Generative AI.
- Content [content] (Required, plain Text): The AI-generated title.
Learn more about Title [title] and structured title [structured_title].
### Description
All descriptions created using generative AI must be provided using the structured description [structured_description] attribute. The structured description [structured_description] attribute uses 2 sub-attributes:
- Digital source type [digital_source_type] (Required for content created using Generative AI): Provide the value “trained_algorithmic_media”, indicating that the description was created using Generative AI.
- Content [content] (Required, plain Text): The AI-generated description.
Learn more about Description [description] and structured description [structured_description].
