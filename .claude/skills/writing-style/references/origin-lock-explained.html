The origin lock, in pictures

Right now people can reach rockpaperprint.com through a back door that skips Cloudflare. The origin lock shuts that door, so only visitors Cloudflare has checked get in.

Think of the website as a concert venue.

Today: a front gate, and an open back door

The website lives on a server we rent from BigRock, in a building shared with other sites. That server is the venue.

In front of it stands Cloudflare, the front gate with ticket checkers. They check every visitor: they stop bad bots, hold back floods, and hand out ready copies of popular pages so the venue stays calm.

The trouble: the venue also has a back door. Anyone who knows the server's street address, or an old alias name for it, can walk straight in.

After the lock: a stamp, and a guard at the back

Now the checkers press an invisible-ink stamp on every hand they check. The stamp is a long secret code that only Cloudflare and the venue know. Visitors never see it.

The back door gets a guard. The guard opens only for a hand with the right stamp. The sneak has none, so the guard says no. On the web that answer is called 403 Forbidden.

The old street sign that pointed down the back alley (the alias name) now says “go round to the front gate”. That answer is called a 301 redirect.

Who still gets in without a stamp

Two callers never pass the front gate, so they could never get a stamp. They have their own keys instead.

Counting people properly

The venue limits how many drinks one person can order in a minute. That is a rate limit. It stops bots from hammering the search box or the login page.

The checkers also write each visitor's real name on the stamp (their real internet address). The website now trusts that name, because the stamp proves a real checker wrote it.

Why it is safe to switch on

  • A backup comes first. Before it changes anything, the script copies the gate file and the WordPress settings file to a safe folder on the server.
  • It won't lock until it sees the stamp. It sends one visitor through Cloudflare and asks WordPress: did that request carry the right stamp? No stamp, no lock. The door stays as it is today.
  • It tests itself. Right after locking it knocks four ways. Through Cloudflare: must open. Straight to the server: must be refused. The old alias: must be sent to the front. The certificate hatch: must not be blocked.
  • It undoes itself. If the site does not open through Cloudflare, or the certificate hatch gets blocked, it puts the old file back on its own, checks the site opens again, and tells you why.
  • --off works any time. One command removes the lock and leaves the site exactly as open as it is today.

The one rule. If Cloudflare is paused, or the stamp rule is deleted, nobody gets stamped any more, so every visitor sees “Forbidden” until you run --off. Before you pause Cloudflare, switch the domain to “DNS only”, move it away, or change that rule: run --off first.

Your three clicks

Open Git Bash in the project folder, C:\xampp\htdocs\Printables.

  1. Run the script the first time. bash production/deploy/apply-origin-lock.sh --go It makes a backup, creates the secret stamp, tells WordPress about it, and then stops on purpose, because Cloudflare is not stamping yet. At the end it prints the secret. Copy it.
  2. Teach the checkers the stamp, in Cloudflare.
    • Open rockpaperprint.com, then Rules, Transform Rules, Modify Request Header, Create rule.
    • Name it RPP edge header. Match: All incoming requests.
    • Choose Set static. Header name X-RPP-Edge. Value: the secret.
    • Click Deploy, then wait a minute.
  3. Run the same command again. bash production/deploy/apply-origin-lock.sh --go This time it sees the stamp arriving, locks the back door, runs its four tests, and tells you it is done.

Later: --check runs the four tests any time. --off removes the lock. Lost the secret? ssh bigrock cat ~/.rpp-edge-secret shows it again.

Little glossary

Origin
The real server where the website lives. The venue.
Cloudflare
The service in front of the server that checks and speeds up every visit. The front gate.
Header
A short labelled note attached to every web request. The stamp is one.
.htaccess
A small rules file the server reads before every request. The guard's instructions.
Certificate
The file behind the padlock and https. It has to be renewed every few months.
Cron
The server's alarm clock for jobs that run on a schedule. The janitor.
403
The server's answer for “Forbidden: you may not come in.”
301
The server's answer for “This has moved for good, go here instead.”
